# Supermarket Sales Data Analysis

## Project Overview

A Python-based project for cleaning, analyzing, and visualizing supermarket sales data to identify useful sales and customer insights.

## Objectives

- Clean and preprocess the sales dataset.
- Handle duplicate and inconsistent data.
- Analyze sales and customer patterns.
- Create meaningful visualizations.
- Generate useful insights from the dataset.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Workflow

Data Collection → Data Inspection → Data Cleaning → Analysis → Visualization → Insights

## Key Results

- **Total Revenue:** ₹830,235.00
- **Transactions:** 300
- **Top Product Line:** Sports and Travel
- **Top City:** Mysuru
- **Top Payment Method:** Cash
- **Top Customer Type:** Member
- **Top Month:** January
- **Top Product by Quantity:** Scarf – 131 units

## Project Files

- `Supermarket_Sales_Data_Analysis.ipynb` – Python analysis notebook
- `supermarket_sales_raw.csv` – Original dataset
- `supermarket_sales_cleaned.csv` – Cleaned dataset
- `Supermarket_Sales_Internship_Report.pdf` – Final internship report
- `requirements1.txt` – Project requirements

This project demonstrates the complete data analysis process, from data cleaning and preprocessing to visualization and insight generation.
